# Cyberhat (2023 a 2024)

Primeira versão do site da Cyberhat, feita em HTML, CSS e JavaScript puro: uma página de apresentação com links para portfólio, GitHub, LinkedIn e contato, e uma calculadora de IMC.

> **O site atual da Cyberhat está em [cyberhat.com.br](https://cyberhat.com.br)**, e os projetos estão no [portfólio](https://portfolio.cyberhat.com.br). Este repositório fica como registro da primeira versão.

## Arquivos

| Caminho | O que é |
|---|---|
| `index.html`, `styles.css`, `scripts.js` | Página inicial |
| `IMC/` | Calculadora de IMC: recebe peso (kg) e altura (cm), valida a entrada e calcula o índice |
| `cyberhat-logo*.png` | Logos |

## Rodando

Abra o `index.html` no navegador, sem instalar nada.
